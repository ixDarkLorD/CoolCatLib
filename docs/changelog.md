# Changelog

What changed in every release of CoolCatLib, for each Minecraft version. CoolCatLib was two mods for a while, CoolCatLib: Core and CoolCatLib: Canvas; Core's releases are part of CoolCatLib's list, and Canvas's own releases, up to the merge, are listed after it. The page is built from each version branch's changelogs, so it's always up to date. Downloads are on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/coolcatlib) and [Modrinth](https://modrinth.com/mod/coolcatlib).
