# Canvas

CoolCatLib's visuals, built on its Core. Package `net.ixdarklord.coolcatcanvas`, in the `coolcatlib` mod (it was the mod CoolCatLib: Canvas before CoolCatLib became one mod). Its asset namespace is still `coolcatcanvas`.

<div class="grid cards" markdown>

-   :material-blur:{ .lg .middle } **[Screen Effects](screen-effects.md)**

    ---

    Full-screen post-processing shaders with live uniforms, and one-line screen tints.

-   :material-weather-night:{ .lg .middle } **[Skyboxes](skyboxes.md)**

    ---

    Layered custom skies, from a JSON file or from code.

-   :material-shimmer:{ .lg .middle } **[World Effects](world-effects.md)**

    ---

    Glowing particles, beams, flashes and trails in the world, rifts that tear open, and effects the server starts.

-   :material-movie-open-outline:{ .lg .middle } **[Cutscenes](cutscenes.md)**

    ---

    Camera paths with letterbox bars, fades, subtitles and markers, from code, resource packs, the server or an in-game editor.

-   :material-waveform:{ .lg .middle } **[Sound Filters](sound-filters.md)**

    ---

    Muffle, roughen and echo the game's sounds, sound by sound or all at once, from the client or the server.

-   :material-format-color-text:{ .lg .middle } **[Text and Colors](text-and-colors.md)**

    ---

    Animated gradients and rainbows, gradient and outlined text, outlines around widgets.

-   :material-dock-window:{ .lg .middle } **[GUI](gui.md)**

    ---

    Draggable windows, scrolling, panels with pan and zoom, slide animations.

</div>
