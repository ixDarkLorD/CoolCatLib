# CoolCatLib: Core

The foundation: one common codebase for Fabric, NeoForge and Forge. Mod id `coolcatcore`, package `net.ixdarklord.coolcatcore`. New here? Start with [Getting Started](../getting-started.md).

<div class="grid cards" markdown>

    ---

    Deferred registers, commands and client registries.

-   :material-access-point-network:{ .lg .middle } **[Networking](networking.md)**

    ---

    Custom payloads, with record payloads getting their codec derived for you.

-   :material-tune-variant:{ .lg .middle } **[Configs](configs.md)**

    Typed configs with server sync, hot reload, presets and migrations.

-   :material-paperclip:{ .lg .middle } **[Attachments](attachments.md)**

    ---

    Your data on entities, block entities and item stacks, saved and synced.

-   :material-package-variant-closed:{ .lg .middle } **[Containers and Menus](containers-and-menus.md)**

    ---

    Slot containers, item transfer and menus that need no screen code.

-   :material-star-four-points-outline:{ .lg .middle } **[Item Decorators](item-decorators.md)**

    ---

    Custom drawing over an item wherever the game draws it in a GUI.

-   :material-wrench-outline:{ .lg .middle } **[Platform and Utilities](platform-and-utilities.md)**

    ---

    Platform information, brewing recipes, datagen helpers and small utilities.
